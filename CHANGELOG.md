# Changelog

## 0.1.0 — 2026-08-01

Portlight's first public release.

### Highlights

- Visual backstage map with plain-English system summaries
- Listening-port visibility with local and network-facing classification
- Running-process CPU and memory table
- Safe public SSH-key fingerprints without private-key access
- Launch-agent, cron-job, and startup-item inventory
- Storage, memory, uptime, and developer-tool views
- Compact native menu bar health summary
- Read-only architecture with no analytics or network service
- Developer ID signing and Apple notarization
